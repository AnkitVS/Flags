# Flags Project 🌍

This project is a collection of country flags created using only **HTML and CSS**.  
It’s part of my practice to improve CSS skills by working with shapes, layouts, and styling — all without images.

## 🎯 Goal
- Explore the power of **pure CSS** for creating visual designs  
- Practice concepts like:
  - Flexbox and positioning  
  - Borders and border-radius  
  - Background colors and layering  
  - Structuring flags using simple `div`

## 🚀 Live Demo
Check it out here: [Flags Demo](https://ankitvs.github.io/Flags/)

## 📂 What’s Inside
- `index.html` → Base HTML structure  
- `style.css` → All flag styles  

## 🏁 Current Flags
- Flag of Åland Islands  
- Flag of Armenia  
- Flag of Austria
